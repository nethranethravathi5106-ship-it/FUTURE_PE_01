AI Website Copy Generator

Task 1 — Future Interns

An AI-powered prompt system designed to generate professional website copy for local businesses.

Objective

The goal of this project is to create a reusable prompt system that can generate website content based on the business type, target audience, services, location, and brand tone.

Business Types

The prompt system is tested with four types of local businesses:

- Salon
- Café
- Clinic
- Digital Agency

Website Content Generated

The system generates:

- Homepage headline
- Homepage subheadline
- About section
- Services descriptions
- Why Choose Us section
- Call-to-action (CTA)
- Contact section

Brand Tones

The system can adapt the content according to different tones, such as:

- Friendly
- Professional
- Modern
- Casual
- Trustworthy
- Results-driven

Outcome

This project demonstrates how structured AI prompts can be used to generate personalized, engaging, and conversion-focused website copy for different local businesses.
